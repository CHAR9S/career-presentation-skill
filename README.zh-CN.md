# Interview Presentation Skill · 求职／面试展示 PPT

**Career Evidence 系列 · 02 / 面试展示**

让真实经历成为面试中讲得清楚、展示得出来的专业价值。

[English](README.md) · [配套简历技能](https://github.com/CHAR9S/canada-resume-skill) · [完整虚构示例](examples/five-minute-interview.md)

## 能做什么

从简历和项目材料中选择与岗位相关的证据，整理成自我介绍、项目案例、个人贡献和岗位匹配展示；同时提供逐页讲述提示、时间分配和事实检查。

它不会把参与写成主导，不会编造业绩，也不会把团队成果全部归到个人名下。没有数字时，用真实的工作过程和定性结果说明价值。

## 如何使用

下载仓库，将 `skills/career-presentation/SKILL.md` 和 `references` 下的两份文件交给 AI，再提供简历、目标岗位、可公开的项目资料。

```text
请使用 Career Presentation 技能，制作一个五分钟的求职面试展示。
根据我的简历和项目资料，突出真实贡献和岗位匹配。
用中文解释，幻灯片用英文，附讲述提示与预计用时。
有制作工具时交付可编辑 PPTX；否则明确说明尚未导出文件。
```

Codex 项目可将完整技能目录放入 `.agents/skills/`，然后调用 `$career-presentation`。它可以独立使用，不要求先安装简历技能。

## 与资料的关系

共同方法来自加拿大就业服务培训资料中的岗位研究和成果表达；PPT 叙事与版式流程是本项目的原创扩展。原课件教的是简历，不是面试展示。公开说明不披露机构名称，不暗示机构背书或培训师联合开发。

这是技能指令包，不是独立 PPT 软件。实际导出取决于 AI 客户端是否有制作工具。第一版没有声称经过跨客户端或真实录用效果验证，也不认为所有加拿大面试都需要 PPT。

## 关于作者

我是 CHAR9S，独立设计师与创作者，拥有 15 年以上动态与视觉设计经验，做过电影片头、CG 内容和品牌视觉，也经营过创意工作室。我的工作一直贯穿从最初想法到最终交付的过程。

这段制作经历也影响了我使用 AI 的方式：先弄清任务，整理素材，做出有依据的创作选择，再检查结果。目前的实践涵盖生成式图像与视频流程，以及设计和网站项目。

在 GitHub 上，我探索的是这段经验的另一种用法：把具体任务中的有效方法整理成可复用的 AI Skills，明确输入、步骤、事实依据和检查方式。设计与这些项目之间的联系，是让复杂的信息更容易理解，让工作方法更容易被使用。

Career Evidence 将信息组织、视觉叙事和事实核对用于求职表达；作者的专业背景是设计与制作，不宣称招聘或职业咨询资质。
